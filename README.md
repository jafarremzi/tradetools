# جعبه ابزار تریدر

نسخه ۰.۳.۰

اپ اندروید (Kotlin + Jetpack Compose) برای معامله‌گران فارکس و کریپتو: فهرست دسته‌بندی‌شده ابزارها و سایت‌ها، چند ماشین‌حساب داخلی و ساعت سشن‌های بازار.

## طراحی (نسخه ۰.۳)
تم تیره مدرن با یک رنگ تأکید نعنایی: کارت‌های گرد با خط‌کادر ظریف، چیپ‌های قرصی، نوار ناوبری شناور، اعداد درشت برای نتیجه‌ها، نوار رنگی شاخص ترس و طمع و نوار زمانی ۲۴ ساعته برای سشن‌ها. فعلاً فقط حالت تیره وجود دارد و اپ مستقل از تنظیم گوشی تیره است. رنگ‌ها در `ui/Theme.kt` (شیء `Palette`) و اجزای مشترک در `ui/Components.kt` هستند. از فونت پیش‌فرض اندروید استفاده می‌شود.

## قابلیت‌های فعلی
- **فهرست ابزارها:** ۵۴ ابزار در ۱۰ دسته، با جستجو، فیلتر بازار (فارکس/کریپتو)، فیلتر «فقط فارسی» و فیلتر دسته. داده از `app/src/main/assets/tools.json` خوانده می‌شود.
- **بازار امروز (جدید):** شاخص ترس و طمع (Alternative.me)، قیمت بیت‌کوین و کارمزد شبکه (mempool.space)، برترین زنجیره‌ها بر اساس TVL (DefiLlama) و نرخ مرجع روزانه ارزها (Frankfurter / بانک مرکزی اروپا). همه APIها رایگان و بدون کلید هستند و مستقیم از گوشی صدا زده می‌شوند. دریافت خودکار حداکثر هر ۵ دقیقه و دکمه دستی حداکثر هر ۳۰ ثانیه؛ اگر یک سرویس خطا بدهد، بقیه بخش‌ها کار می‌کنند. نرخ ECB روزانه است و زنده نیست.
- **ماشین‌حساب‌ها (کاملاً آفلاین):** اندازه پوزیشن (فارکس و کریپتو)، ریسک به ریوارد، سود و زیان با کارمزد، قیمت تقریبی لیکوئید. ورودی با ارقام فارسی هم پذیرفته می‌شود.
- **ساعت بازار:** وضعیت باز یا بسته بودن سیدنی، توکیو، لندن و نیویورک و ساعت تهران.
- **علاقه‌مندی‌ها:** ذخیره محلی با DataStore.
- **هشدار ریسک:** هنگام اولین اجرا و از دکمه ⓘ بالای صفحه.
- رابط همیشه راست‌به‌چین است و از حالت تاریک پشتیبانی می‌کند.

## فرض‌های طراحی
- حداقل اندروید ۸ (API 26).
- تمام فیلد `access` ابزارها فعلاً `unknown` است و باید دستی بررسی شود (`direct` یا `needs_vpn`).
- نسخه‌های ابزار ساخت عمداً محافظه‌کارانه و هماهنگ با هم انتخاب شده‌اند: AGP 8.7.3، Kotlin 2.0.21، Compose BOM 2024.10.01، Gradle 8.9، compileSdk 35. بعد از اولین ساخت موفق می‌توان آن‌ها را به‌روز کرد.
- Gradle Wrapper داخل پروژه نیست (فایل باینری jar بدون شبکه ساخته نمی‌شود). Workflow گیت‌هاب مستقیماً Gradle 8.9 را نصب می‌کند. برای ساخت محلی در Android Studio پروژه را باز کنید؛ یا دستور `gradle wrapper --gradle-version 8.9` را یک بار اجرا کنید.

## ساخت APK با GitHub Actions
1. یک مخزن خالی در GitHub بسازید و محتوای همین پوشه را در شاخه `main` قرار دهید (Push).
2. به تب **Actions** مخزن بروید. با هر Push، Workflow به نام **Android CI** اجرا می‌شود. اجرای دستی هم از دکمه **Run workflow** ممکن است.
3. وقتی اجرا سبز شد، آن را باز کنید و از بخش **Artifacts** فایل `trader-toolbox-debug-apk` را دانلود کنید. داخل آن فایل `app-debug.apk` است.
4. APK را به گوشی منتقل کنید و نصب کنید (اجازه «نصب از منابع ناشناس» لازم است).
5. اگر اجرا قرمز شد، آرتیفکت `build-reports` را دانلود کنید یا لاگ مرحله شکست‌خورده را برای رفع خطا ارسال کنید.

## به‌روزرسانی فهرست ابزارها بدون انتشار نسخه جدید
فایل `tools.json` را روی یک آدرس https بگذارید و همان آدرس را در `app/src/main/java/app/tradertoolbox/Config.kt` (مقدار `REMOTE_TOOLS_URL`) بنویسید. اپ در هر اجرا فایل را می‌خواند و فقط اگر فیلد `updated` جدیدتر باشد آن را ذخیره می‌کند. اگر این مقدار خالی بماند، اپ فقط از فهرست داخلی استفاده می‌کند.

## قبل از انتشار در مایکت
- **نام پکیج (`applicationId`)** فعلاً موقت است (`app.tradertoolbox`). پیش از اولین انتشار نهایی‌اش کنید؛ بعداً قابل تغییر نیست.
- **امضای Release:** یک Keystore بسازید، چند نسخه پشتیبان از آن نگه دارید و رمزها را فقط در GitHub Secrets بگذارید. برای آپدیت‌های بعدی همیشه باید همان کلید استفاده شود. Debug APK برای انتشار عمومی مناسب نیست.
- **قوانین مایکت:** شرایط فعلی انتشار (به‌ویژه برای اپ‌های مالی و معاملاتی) را از پنل توسعه‌دهندگان بررسی کنید.
- **صفحه حریم خصوصی و شرایط استفاده** را آماده کنید.
- **اسپانسرها:** پیش از هر قرارداد اسپانسری یا همکاری در فروش، وضعیت حقوقی و تحریمی طرف مقابل را بررسی کنید.
- **آیکن و اسکرین‌شات** مناسب فروشگاه را آماده کنید.

## محدودیت‌های «بازار امروز»
- فقط منابع بدون کلید استفاده شده؛ چون کلید داخل APK قابل استخراج است. منابع کلیددار (CoinGecko، CoinMarketCap) یا پولی (الان‌چند برای نرخ دلار و طلای ایران) باید از پشت یک لایه کش سمت سرور وصل شوند.
- از ایران، دسترسی به این سرویس‌ها بررسی نشده و ممکن است بعضی‌ها بدون تغییر IP باز نشوند.
- شرایط استفاده و الزام ذکر منبع هر سرویس را پیش از انتشار بخوانید. نام منبع زیر هر کارت نمایش داده می‌شود.
- داده‌ها ذخیره نمی‌شوند؛ با بستن اپ از بین می‌روند.

## ساختار پروژه
```
app/src/main/java/app/tradertoolbox/
  data/    مدل‌ها، خواندن tools.json، ذخیره علاقه‌مندی‌ها (DataStore)
  logic/   ماشین‌حساب‌ها، ساعت سشن‌ها، فیلتر، تبدیل ارقام (بدون وابستگی به اندروید و قابل تست)
  ui/      صفحه‌ها و اجزای Compose
app/src/test/   تست‌های واحد ماشین‌حساب‌ها، سشن‌ها و فیلتر
```
